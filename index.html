When a strict rule traps the AI agent

Imagine a rule for an AI agent: "always use the real tool, and never fake a result." Sounds safe. But what if the tool exists and is switched off right now? Try it below: you play the agent.

What this does not show

  • It does not test a real AI model. It runs the paper's rule table, so it shows what the rules allow, not what any model does.
  • The 10% and 5-call numbers are the paper's assumptions, not measurements of any platform. Exposure is not the same as an actual deadlock rate.
  • Real systems may already have retries or escalation that hide this trap. The paper's proposed experiment has not been run.
